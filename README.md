## 🚀 How to Run (Direct Browser Execution)

1. **Extract this zip folder** to any location on your computer or phone.
2. **Double-click `index.html`** or **`login.html`** to open it in Chrome, Edge, Firefox, Brave, or Safari.
3. Everything runs **instantly** without running any terminal commands or installing software!

## 🌟 How the Client Storage Engine Works

- The entire platform data (users, files, folders, shares, projects, settings) is managed autonomously in the browser using the included `js/storage-engine.js`.
- File uploads calculate **real byte sizes** and update your **5 GB storage quota** dynamically.
- Uploads are blocked when the 5 GB quota is reached, and deleting files reclaims storage immediately.
- Web projects run inside isolated sandbox iframes (`srcdoc`) and integrate with the official StoreHub SDK (`store.js`).
